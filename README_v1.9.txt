Pose Camera v1.9
- Keeps the v1.8 CameraX video + ML Kit pose tracking base.
- Adds a local Saved Poses library helper (stored in app preferences).
- Adds a quick Poses toolbar entry.
- Adds Save current pose when the existing reference URI state is detected.
- Saved poses can be reused/deleted through the library component.

Note: v1.9 is an incremental build. The camera/video pipeline from v1.8 is intentionally preserved.
